Source lives in [ijakesilverstein/study-table](https://github.com/ijakesilverstein/study-table). The combined V169 app is [public/study-table-v169.html](https://github.com/ijakesilverstein/study-table/blob/v169/public/study-table-v169.html). Open that file on GitHub, choose **Download raw file**, then open the saved HTML in a browser. A private repository requires an authorized GitHub login. A GitHub source preview is not the running app.

The locally packaged `Study_Table_V169.zip` contains that exact HTML; its SHA-256 is `ab242515917773d6df55751c810a245f63724f86482d0b31fd07d6eb05b05820`. The app’s own download control saves the same file as `Study_Table_V169.html`. Previous numbered artifacts and release tags remain available.

The **Check reconciled V169 download** Actions workflow builds the combined app, runs `npm run test:latest`, and packages HTML/ZIP without deploying. After a successful hosted run, open **Actions → Check reconciled V169 download → the run → Artifacts → study-table-v169-downloads**. That archive contains `Study_Table_V169.html` and `Study_Table_V169.zip`. Artifacts expire after 30 days; the committed HTML and release tag remain. The older **Check source and lessons** workflow continues to check and package the V136 foundation. Local tests and a successful Git push do not establish that a hosted run has passed; no ready hosted artifact is claimed here.
