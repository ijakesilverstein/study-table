# GitHub source and downloadable files

Source lives in [ijakesilverstein/study-table](https://github.com/ijakesilverstein/study-table). The V136 standalone app is [public/study-table-v136.html](../public/study-table-v136.html). Open the file on GitHub and choose **Download raw file**, then open the saved HTML in a browser. A private repository requires an authorized GitHub login. A repository preview is not the running app.

The HTML is 7,140,086 bytes, SHA-256 `26e79a555b74d24b61edb506e13cbddcde26b1e859b099fc5e47107721750cd0`. The locally packaged `Study_Table_V136.zip` contains that exact HTML; its SHA-256 is `2e76c2463858a166bd3e297a7cab56aba90e704ca522a9b786325e429cbd5f76`. The app’s own download control saves the same standalone file. Earlier artifacts and release tags remain available; the original V132 release can be accessed through tag `v132` even where later V132 development updated main.

The **Check source and lessons** GitHub Actions workflow verifies the committed HTML against source, runs the registered checks, and packages HTML/ZIP downloads. After a successful hosted run, open **Actions → Check source and lessons → the run → Artifacts → study-table-downloads**. That archive contains `Study_Table_V136.html` and `Study_Table_V136.zip`. Artifacts expire after 30 days; committed HTML and release tags remain. Local tests and a successful Git push do not establish that a hosted run has passed. The GitHub API is restricted in this workspace, so no ready hosted artifact is claimed without separate verification.

This pass adds three visual teaching companions while keeping all 87 units, the V135 lesson rewrites and shared medicine/business additions. See [the teaching and verification scope](VISUAL_COMPANIONS_V136.md) and [the concurrent development checkpoint](CONCURRENT_INTEGRATION.md). The user requested **no Vercel publication**. No Vercel deploy is performed, and repository configuration disables Git-triggered deployments. GitHub source delivery and local download checks are separate from website publication. Local packaging retains previous staged downloads, checks that the online app and HTML have identical bytes, and verifies that the ZIP extracts the same file; this does not mean the staged website was published.
